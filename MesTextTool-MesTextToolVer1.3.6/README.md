# Da Capo 3 With You MES reference

This is a local DC3WY-only adaptation of MesTextTool 1.3.6.
The supported script list contains only `dc3wy` (version `0xA09F`).
The original license is retained in `LICENSE`.

For the maintained importer/exporter, use `DC3WYMesTextTool_GUI.exe` in
`../bin/Release/net8.0-windows`. Its GUI and CLI share the validated DC3WY
text wrapping, name grouping, and layout reports described in the main README.
This C++ source is retained as a format reference and is not the GUI backend.
